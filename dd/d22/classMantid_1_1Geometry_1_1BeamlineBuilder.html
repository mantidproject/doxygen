Detailed Description

BeamlineBuilder : builds ComponentInfo and DetectorInfo directly, without a legacy component tree.

The instrument is described as a tree of nodes. Each node is added under a parent node that was added before it, and has a position and rotation relative to that parent. The first node has no parent and is the root. Nodes are referred to by the handle returned when they are added. Handles are not component indices: build() lays the components out as InstrumentVisitor does.

  • Detectors come first, ordered by detector ID, so a detector's component index is its detector index.
  • The other components follow in post-order (each after its children, the root last).
  • Children are listed in the order they were added.
