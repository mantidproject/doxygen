Detailed Description

InstrumentMetadata : metadata related to the entire instrument.

  • valid-from/to dates
  • source IDF filename
  • raw IDF XML text
  • default instrument-view type/axis
  • physical/neutronic instrument split for indirect-geometry instruments Created at instrument load and read-only thereafter.
