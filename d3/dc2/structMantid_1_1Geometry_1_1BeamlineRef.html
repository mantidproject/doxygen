Detailed Description

BeamlineRef : an instrument as Instrument 2.0 holds it.

The ComponentInfo and DetectorInfo are cross-linked, so they are always held together. Both share one parameter store. The metadata is null if none was given. Made by makeBeamlineRef, the two pointers share one owner, so holding either keeps both alive.
